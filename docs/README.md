# EdgeKeys — Docs

This folder contains the hackathon materials: demo script, submission write‑up, and placeholders for screenshots and demo video.

## Contents
- `demo-script.md` — a 60–90s narration you can follow while recording
- `submission.md` — copy/paste text for the hackathon form
- `solana-pay-test.md` — clear step-by-step test flow (UI + curl)
- `screenshots/` — put PNG/JPG images here for README and submission
- `video/` — place your final demo file here (e.g., `edgekeys-demo.mp4`)
- `assets/` — artwork like the Blackbox 0G badge

## Suggested README links
After you upload screenshots and the video link, add to the root `README.md`:

```md
- Demo video: <YOUR_LINK>
- Screenshots: see [/docs/screenshots](./docs/screenshots)
```
